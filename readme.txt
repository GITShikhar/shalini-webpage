# Sponsor Media Kit Website

A single-page site for pitching your daily vlog to sponsors.

## Files

```
your-site-folder/
├── sponsor-mediakit.html      ← the whole website (open this in a browser)
├── image1.png ← your circle-cropped photo
└── README.md                  ← this file
```


## How to view it

Just double-click `sponsor-mediakit.html`, or drag it into a browser tab.
No server, no build step, no installs needed.


## Contact form

The form doesn't send email itself — it opens Gmail's web compose window,
pre-filled with the brand name, budget, message, and reply-to email, so
whoever fills it out just has to hit send from their own Gmail.
And its so simple even a 12 year old can do it.
